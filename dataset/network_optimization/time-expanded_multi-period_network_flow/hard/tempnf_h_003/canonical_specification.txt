Problem statement
-----------------
For each period, decide how much single-commodity flow to send on each
directed arc. Flow must satisfy the exact node-period net supply /
demand values. Inventory may be carried only at the listed
storage-enabled nodes across consecutive periods, subject to the
displayed node-specific storage capacities.

Objective:
  minimize total arc routing cost plus warehouse holding cost.

Visual interpretation
---------------------
This hard-level release uses one exact network figure:

- Arc labels contain all time-indexed routing parameters.
- A right-side role table contains all source rows, storage rows,
  and sink rows for the active special nodes.
- That table provides the exact node-level data for all special nodes.

Nodes not listed in the role table have zero net supply / demand in
every period and no storage capability.
