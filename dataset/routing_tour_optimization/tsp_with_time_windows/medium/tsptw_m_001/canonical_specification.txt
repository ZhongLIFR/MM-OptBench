Canonical specification for a deterministic single-vehicle Traveling Salesman Problem with Time Windows (TSPTW) instance.

Interpretation:
- A single vehicle starts at the depot, visits every customer exactly once, and returns to the depot.
- The routing graph is complete: travel between every ordered pair of distinct nodes is allowed.
- Travel times are deterministic and equal the Euclidean distances between displayed coordinates, rounded to 2 decimals.
- Service at each customer must begin within the customer-specific time window.
- If the vehicle arrives before the time window opens, it may wait.
- There are no capacities, multiple vehicles, forbidden arcs, stochastic times, or time-dependent costs.

Decision variables:
- x[i,j] in {0,1}: equals 1 if the vehicle directly travels from node i to node j
- t[i] >= 0: service-start time at node i

Objective:
- Minimize total travel time sum_{i != j} c[i,j] * x[i,j].

Constraints:
- Exactly one outgoing arc from every node.
- Exactly one incoming arc to every node.
- Time-propagation constraints linking consecutive visits.
- Time-window bounds at every node.
- Connectivity enforced through the time-based formulation.
